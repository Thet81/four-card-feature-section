### What I learned
- I have learned how to use `css grid` to place the `html` elements in two dimensional structure.
- Now I am familar with some useful grid properties such as `justify-content`,`align-content`, `justify-items` and `align-items`. I have never used these properties before and now I am aware of situations where these properties could be useful.
